1. Use Case Summary

Goal: Rebuild the public CHN Bariatric & Medical Weight Loss marketing page as a fast, self-contained static site, and use it as a working deployment-pipeline test for Astro on Cloudflare — while adding one live feature (an AI "Information at a glance" Q&A panel) that talks to an internal Databricks Genie space.

Business value: The content pages cost nothing to serve — they are static assets on Cloudflare's CDN with no origin round-trip. The one interactive feature is isolated to a single edge function that holds the Azure credentials server-side, authenticates a service principal, and proxies vetted questions to Genie. Adding, changing, or removing the AI panel touches exactly one file and never affects how the rest of the site is built or served.

Key property: Static content and the dynamic AI route are the same Astro project but independent at runtime — the CDN serves HTML with no code execution, and the Worker runs only when the panel calls /api/genie. Neither depends on the other being healthy.

2. What the System Does

  • Rebuilds the CHN Bariatrics landing page in Astro — header, hero, assessment CTA, services, FAQ, support, locations, and providers — as components under src/.
  • Prerenders every route to static HTML/CSS at build time; images are hot-linked from ecommunity.com.
  • Ships one client-side island: the collapsible "Information at a glance" panel with suggestion chips and a free-text question box.
  • Exposes one server route, /api/genie, that runs as a Cloudflare Worker.
  • In that route: authenticates a Microsoft Entra (Azure AD) service principal via the client-credentials grant, caches the bearer token per isolate, and calls the Databricks Genie conversation API.
  • Starts or continues a Genie conversation, polls the message until COMPLETED, extracts the answer from its attachments, and returns { answer, conversationId } as JSON.

3. Project Context

The project lives in the bariatrics/ subdirectory of the IndyCrew/cloudflare repo; all commands run from there. Astro's Cloudflare adapter emits a static client bundle plus a Worker entry point. Data flows one direction: browser → edge function → Azure AD → Databricks Genie → back. There is no database, no CMS, and no server the site owns — Genie is the only upstream, reached only through the one function.

8. Edge Function Concept

Route: POST /api/genie  ·  Body: { question, conversationId? }  ·  Runs as: a Cloudflare Worker (the rest of the site is prerendered).

Responsibilities:

  • OPTIONS — CORS preflight (* origin, POST only, Content-Type header).
  • Validate — reject empty questions and anything over 1000 characters with a 400.
  • getToken() — client-credentials grant against Entra; cache the token per isolate until 60s before expiry.
  • genieFetch() — thin wrapper over /api/2.0/genie… with the bearer token; turns non-2xx into a 502 with a truncated detail string.
  • Start vs. continue — no conversationId → start-conversation with conversation_type = mode; otherwise POST a message to the existing conversation.
  • pollMessage() — poll until COMPLETED; fail fast on FAILED/CANCELLED; 504 after ~55s.
  • answerFromMessage() — prefer attachment text, then query descriptions, then msg.content.
Statefulness note: the token cache is per-isolate and non-durable — it only avoids re-auth during bursts on a warm isolate. Genie conversation continuity is the client's job: the browser holds conversationId and sends it back on follow-up questions.

10. Summary

"CHN Bariatrics is an Astro rebuild of a single Community Health Network marketing page, prerendered to static HTML and served from Cloudflare's edge with no origin. The one exception is /api/genie, a Worker route that opts out of prerendering: it authenticates a Microsoft Entra service principal, proxies a visitor's question to an internal Databricks Genie space, polls until the answer is ready, and returns just the answer text — so the 'Information at a glance' panel can be conversational without any Azure or Databricks credential ever reaching the browser."

"The architectural value is the isolation. The content build, the AI route, and the upstream Genie space are each independently swappable — restyling the page, changing Genie modes or spaces, or removing the panel entirely each touch only one layer, and a Genie outage never affects how the rest of the site is served."
